## Scope and artifacts

The sanitizer run instruments the host harness; it does not instrument the
compositor or loaded plugin. Application checks use disposable profiles and do
not cover signed-in Discord account actions, calls or every browser extension.
Applications and service wrappers that discard launch/activation correlation
retain native placement. Other compositor, GPU and launcher versions are outside
this compatibility matrix.

The physical deployment uses personal systemd user overrides for Walker and
Elephant, with the matching provider directory supplied to both services.
Walker performs provider discovery itself; supplying that directory only to the
Elephant daemon caused a startup crash during rollout and was corrected before
the passing live checks. Distribution binaries and Omarchy-managed source files
remain intact.

Local logs and result JSON are retained under `build/verification/2026-09-06/`.
Physical screenshots stay in the private temporary artifact directories printed
by the tests; they are excluded from the repository because they may contain
desktop content. Re-run the release gate on any changed plugin or companion build
before publishing it.
